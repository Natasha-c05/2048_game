2048 terminal game

How to play:
-game starts with 2 number tile numbered 2, rest of the tiles are empty.
-players can move up (U), down (D), left (L) or right (R), whith a goal to merge both tiles.
-When you merge two tiles together, the 2 numbers add up.
(tiles can only mere if they are the same number tiles. so 2 with 2,4 with 4 and so on).
-As we merge 2 tiles togther, a new tile slides into the grid randomly from any direction, any tile thats a multiple of 2.
-Keep merging the numbered tiles and new more tiles will come in.
-You win if any of the tiles equal 2048 
-You lose if all the empty cells are filled, no moves remaining and no tile is equal to 2048.
